Read the thread before its summary. Open context only when it can change the reply, owner, or next move.

| Signal | Move |
| :--- | :--- |
| A reply is safe and supported | Reply |
| Another person owns the decision | Assign |
| The thread needs comparison or synthesis | Ask ubik |
| Evidence or an external owner is missing | Wait |
