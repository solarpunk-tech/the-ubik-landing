## What we are building

- Pin accounts, lanes, SKUs, suppliers, or shipments to a project.
- One memory scope across every meeting, task, and thread the project touches.
- Shared with the operators working on it; external collaborators can be looped in via email.
- A live brief — what changed since last review, what is blocked, what needs you next.

Until Projects ships, use [Ask ubik](/workflows/ask-ubik) to assemble the same context across linked work.
