## Four habits

<Columns cols={2}>
  <Card title="Read the source" icon="search-check">
    Open the message, record, or file that supports the proposed move.
  </Card>
  <Card title="Name the owner" icon="user-round-check">
    Open means your team owes the move. Waiting means somebody else does.
  </Card>
  <Card title="Review every write" icon="shield-check">
    Check customer promises, price, timing, and system changes before approval.
  </Card>
  <Card title="Leave a receipt" icon="history">
    Close work with the reason, evidence, and reviewer attached.
  </Card>
</Columns>
