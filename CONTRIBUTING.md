# Contributing to Ubik Landing

Thank you for considering a contribution! This guide covers the basics to get you started.

## Installing dependencies
Make sure you have **pnpm** installed, then run:
```bash
pnpm install
```

## Running the development server
Start the Vite dev server with:
```bash
pnpm dev
```
The site will be available at `http://localhost:5173`.

## Branch naming convention
Use clear, lowercase names with hyphens and one of the following prefixes:
- `feature/[name]` – new features
- `bugfix/[name]` – bug fixes
- `docs/[name]` – documentation changes
- `chore/[name]` – maintenance tasks

Example: `feature/login-flow`

## Opening a pull request
1. Create a new branch from `main` following the naming convention.
2. Make your changes and commit with descriptive messages.
3. Push the branch to the remote repository.
4. Open a pull request targeting the `main` branch.
5. Ensure the PR passes all checks and includes any necessary documentation updates.

We appreciate your help in improving Ubik Landing!
