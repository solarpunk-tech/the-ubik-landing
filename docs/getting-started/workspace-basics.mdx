The workspace is built around one question: what needs action before it slips?

## Main areas you will use

| Area | Purpose |
| --- | --- |
| Operating queue | Prioritized work items that need review, assignment, or approval. |
| Source context | The email, document, meeting, chat, or system detail Ubik used to explain the item. |
| Action panel | The reply, task, approval, or handoff Ubik suggests. |
| Activity trail | A record of who reviewed, edited, approved, rejected, or assigned the work. Managers use this to see what happened without asking five people. |

## Queue states

| State | When you see it |
| --- | --- |
| <span className="ux-label is-primary">Now</span> | Review this before moving to lower-priority work. |
| <span className="ux-label is-support">Found</span> | ubik detected a change that may affect downstream plans. |
| <span className="ux-label is-destructive">Analyse</span> | The item needs human review before a recommendation is safe. |
| <span className="ux-label is-success">Ready</span> | The action is prepared and waiting for approval or assignment. |

## Handoff modes

Every queue item carries a handoff chip that tells you who has the next move.

<span className="ux-handoff is-human">Human → Review</span> &nbsp;
<span className="ux-handoff is-agent">Agent → Drafting</span> &nbsp;
<span className="ux-handoff is-system">System → ERP queue</span> &nbsp;
<span className="ux-handoff is-final">Final → Committed</span>

## Theme and readability

Ubik supports light and dark modes. Choose the mode that gives your team the clearest daily read, especially when reviewing grey secondary text, source snippets, and long approval trails.
