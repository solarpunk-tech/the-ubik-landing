The current shipping motion uses the same primitives — Ask ubik, Inbox, Tasks, Meetings — composed by hand. Workflows turns those compositions into named, reusable playbooks.

## What we are building

- Visual builder for chaining agents across inbox, meetings, tasks and ERP.
- Approval gates at every commercial decision point.
- Per-workflow memory and audit trail.
- Templates for the five seafood-native loops: RFQ → quote, PO ingestion, transit-aware scheduling, VMI pull-rate, lot traceability.

Until Workflows ships, the [daily operating queue](/workflows/daily-operating-queue) and [Ask ubik](/workflows/ask-ubik) carry the same outcome — just operator-composed.
