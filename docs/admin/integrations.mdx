Connected tools give ubik the source context behind an operator task. Access is scoped by the workflow, the workspace admin, and whether the integration is read-only or allowed to make reviewed updates.

## Read and write boundaries

<Tabs>
  <Tab title="Read" icon="eye">
    ubik may retrieve the messages, files, fields, records, or events required for the approved workflow. A connection does not automatically make every workspace object available.
  </Tab>
  <Tab title="Draft" icon="file-pen-line">
    ubik may prepare a reply, task, record update, or approval packet without committing it to the source system.
  </Tab>
  <Tab title="Reviewed writeback" icon="shield-check">
    An approved operator action may update the connected system. The reviewer, source, timestamp, and resulting state remain attached to the action.
  </Tab>
</Tabs>

## Review before connecting a tool

<Steps>
  <Step title="Name the workflow">Document which operator task needs the connection and what outcome it supports.</Step>
  <Step title="Limit the source scope">Choose only the accounts, inboxes, channels, folders, objects, or fields required by the workflow.</Step>
  <Step title="Choose the action boundary">Keep the tool read-only, allow drafts, or permit reviewed writeback.</Step>
  <Step title="Assign an owner">Name who can renew, revoke, or troubleshoot the connection.</Step>
  <Step title="Plan for failure">Decide how stale data, expired consent, missing permissions, and provider downtime should appear to operators.</Step>
</Steps>

<AccordionGroup>
  <Accordion title="Why did a connected-app suggestion disappear?" icon="circle-help">
    Suggestions appear only when the required app is connected and available to the current workspace. Check the app connection, permissions, and source scope.
  </Accordion>
  <Accordion title="Why is the data stale?" icon="refresh-cw">
    Look for expired OAuth consent, changed permissions, renamed folders, moved fields, provider downtime, or a workflow that no longer includes that source.
  </Accordion>
  <Accordion title="Does a connection allow automatic writeback?" icon="shield-alert">
    No. Read access, drafting, and reviewed writeback are separate boundaries. The workflow must explicitly permit the action.
  </Accordion>
</AccordionGroup>
