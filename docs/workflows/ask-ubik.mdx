| Operator task | Connected sources | Useful output | Review before acting |
| :--- | :--- | :--- | :--- |
| Daily morning brief | GitHub · Notion · Slack | One prioritized brief grouped by source | Urgent items and the top three actions |
| Catch up on Slack | Slack | Decisions, mentions, open questions, and overdue replies | Sensitive or ambiguous threads |
| PRs to review | GitHub | Review queue with change, risk, status, and owner | Failing checks and blocked releases |
| Prepare for a meeting | Calendar · meetings · workspace knowledge | Recent decisions, open tasks, risks, and questions | Stale owners and unsupported assumptions |

<Steps>
  <Step title="Name the work">State the decision, review, comparison, or action.</Step>
  <Step title="Attach sources">Add only the apps, files, or workspace knowledge that can change the answer.</Step>
  <Step title="Set the contract">Require sources, dates, owner, uncertainty, and next move.</Step>
  <Step title="Review">Open the cited context before a reply, task, or writeback moves.</Step>
</Steps>
