Start with who owes the next move. Open work belongs to you or your team. Waiting work belongs to another owner. Closed work keeps the receipt or reason that proves it moved.

| State | Read it as |
| :--- | :--- |
| Open | We owe the next move |
| Waiting | They owe the next move; ubik watches |
| Probably closed | Evidence suggests the work moved |
| Closed today | A reason or receipt confirms completion |
